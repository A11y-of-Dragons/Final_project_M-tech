# Final_project_M-tech

## Technology Stack
- **Frontend**: HTML, CSS, Bootstrap
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **AI Integration**: AI Assisted Coding
- **Deployment**: Docker, and possibly Google Cloud


## Getting Started
1. Clone the repository: `https://github.com/A11y-of-Dragons/Final_project_M-tech`
2. Install dependencies: `npm install`
3. Start the app: `npm run dev`
